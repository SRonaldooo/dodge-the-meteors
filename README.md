# Dodge the Meteors

A small browser survival game: move your ship, avoid the falling meteors, and beat your high score.

## Play

After GitHub Pages is enabled, the game will be available at:

`https://sronaldooo.github.io/dodge-the-meteors/`

## Controls

- **Move:** Arrow keys or `W`, `A`, `S`, `D`
- **Pause / resume:** `P` or the on-screen button
- **Restart after a crash:** `Enter`, `Space`, or the on-screen button

The best score is saved in the current browser.

## Run it locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Push this repository to GitHub.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose `main` and `/ (root)`, then click **Save**.

GitHub will give you the live link within a few minutes.
