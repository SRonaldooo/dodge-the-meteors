# Starfall: Last Light

An arcade survival game about one pilot answering a distress call from Outpost Luma. Fly through an increasingly dangerous asteroid field, recover supply flares, and keep the station's signal alive.

## Play online

https://sronaldooo.github.io/dodge-the-meteors/

## How to play

- **Fly:** arrow keys or `W`, `A`, `S`, `D`.
- **Star Pulse:** press `Space` when the meter is full. It clears nearby threats.
- **Pause:** press `P` or use the Pause button.
- **Sound:** press `M` or use the sound button.
- **Touchscreens:** use the on-screen directional pad and Pulse button.

Avoid rocks, fast comets, and weaving drones. Near misses add bonus points. Supply flares grant temporary shields, hull repairs, or pulse charge. The game gets harder each sector. Your best score is saved in this browser.

## Flight protocols

- **Cadet:** slower hazards and a gentler spawn rate.
- **Pilot:** standard patrol conditions.
- **Ace:** faster, more frequent threats and a higher score multiplier.

## Run locally

Open `index.html` in a modern browser. The game uses plain HTML, CSS, and JavaScript; no build step or dependencies are required. Sound is synthesized by the browser and can be muted.
